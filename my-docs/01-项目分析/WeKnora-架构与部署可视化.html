1系统分层：三个子系统

核心只需 4 个常驻容器；其余组件全部是 opt-in profile。

2PDF / DOCX / XLSX 入库链路

不需要任何外部转换工具——转换能力已内置在 docreader 镜像里。

格式 → 解析器归属：xlsx/xls → ExcelParser（openpyxl/xlrd/pandas）｜docx → Docx2Parser（python-docx，失败回落 MarkItDown）｜doc → DocParser（antiword）｜pdf → PDFParser（pypdfium2 + pypdf）｜ppt/pptx → MarkItDown 引擎。

3多领域隔离与跨领域共享

隔离靠 Tenant（空间）+ tenant_id 行级过滤；共享只有「整库」和「Agent 只读」两种粒度。

4内网（无互联网）部署依赖

除内网 LLM API 外，还必须准备离线镜像与 Embedding API —— 后者最易被漏掉。

① 离线镜像必须
weknora-app / weknora-ui
weknora-docreader（最大，含 LibreOffice + Playwright + JDK）
paradedb:v0.22.6-pg17 / redis:7.0-alpine
用 docker save/load 或私有 registry 搬运
② Embedding API必须
没有它完全无法入库与检索，比 LLM 更底层。
接口：OpenAI 兼容 /v1/embeddings
仓库内无任何本地模型文件，全为远程 API
③ LLM API必须
问答 / 摘要 / Agent 依赖。
接口：OpenAI 兼容 /v1/chat/completions
UI 配置或声明式 config/builtin_models.yaml（支持 ${ENV}）
④ 中间件随镜像自带
ParadeDB（PG17 + BM25 + pgvector）+ Redis 7
✓ 由 compose 提供，无需额外准备

可选的模型能力（按需，不配即不启用）

用途必须性缺失时的现象
Rerank强烈建议检索质量下降（可关闭，不影响主链路）
VLM可选扫描件 PDF / 图片无法出文字与语义描述
ASR可选音频文件无法转写

默认配置里 8 处会主动出网的位置（逐个处置）

联网点默认行为处置
Ollamahost.docker.internal:11434内网替代，或 OLLAMA_OPTIONAL=true（仅告警不阻断）
网络搜索DuckDuckGo/Bing/Google/Tavily/Baidu/Exa/Metaso不配置即不启用
数据源同步飞书 / Notion / 语雀 / GitLab / IMA / RSS不配置即不启用
Langfusecloud.langfuse.com关闭，或内网自建（--profile langfuse）
对象存储COS / TOS / S3 / OSS / OBS / KS3用 STORAGE_TYPE=local 或内网 MinIO
外部解析服务MinerU / PaddleOCR-VL不配置即不启用
Agent 沙箱Docker / E2B / Cube默认关闭，无需处理
前端图标 CDNtdesign.gtimg.com✓ 已内置离线保护，图标本地化
不要在内网源码编译。构建期存在多处联网：Dockerfile.app 拉 uv 安装脚本、Dockerfile.docreader 下载 protoc 与 Playwright webkit 内核、build_browserskill.sh git clone、前端 npm 依赖。
