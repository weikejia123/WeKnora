# Wiki 内容生成要求
本要求用于规范“预算执行和其他财政收支的审计工作报告”知识库的摘要、页面与首页表达重点。当前覆盖全国 30 个省级行政区 2024、2025 年度的审计工作报告、整改报告及配套文字解读与图解，暂无中央本级与市级报告；扩展时按第七节口径补充。引用、合并与防幻觉规则由系统固定维护；修改后需重新解析，才会影响已有内容。

## 一、面向读者与总体目标
主要读者为审计人员、人大预算审查人员、财政监督人员、政策研究人员及知识库维护人员。生成内容应严谨、规范、可检索，服务于四类核心意图：
1. 按省份和年度快速定位报告；
2. 按审计板块和问题类型检索审计发现；
3. 按涉及主体和整改状态追踪问题；
4. 支持跨年度、跨省份同类问题比对。

## 二、摘要表达重点
摘要用于快速判断条目属于哪个省份、哪一板块、哪类问题，建议 3—5 句或 150—250 字。
必须写清：**省份**（或报告主体）、**报告类型**（审计工作报告/整改报告/文字解读/图解）、**报告年度与审计期间**、**审计板块**（财政管理审计、部门预算执行审计、重点专项审计、国有资产审计、审计建议、整改情况等）、**问题类型**（预算编制、预算执行、资金绩效、债务管理、政策落实、资产管理、财经纪律等）、**涉及主体**、**核心发现**与**整改状态**。
按内容类型组织摘要：
- **报告概览类**：“省份—年度—报告主体—审计期间—审计范围—总体评价”；
- **板块审计类**：“板块名称—审计对象—主要发现类型—问题金额/数量—审计建议方向”；
- **问题条目类**：“问题定性—涉及主体—主要事实—金额—定性依据—整改状态”；
- **审计建议类**：“建议方向—针对问题—责任主体—政策依据”；
- **整改情况类**：“整改主体—整改事项—整改措施—整改结果—追责问责情况”；
- **跨年度比对类**：“问题领域—年度变化—连续反映/首次反映/整改后未再出现”。
保留金额、比例、问题数量、涉及单位数等关键数据，注明报告年度、审计期间、省份和单位。总体评价应标注“总体评价”，不与具体审计发现混淆。审计期间已整改问题应单独标注“审计期间已整改”。

## 三、报告类页面表达重点
默认结构：**标题与一句话定位 → 报告基本信息 → 总体评价 → 分板块审计发现 → 审计建议 → 整改与追责情况 → 跨年度比对 → 关联条目**。
报告基本信息包括：报告全称、省份、报告年度、审计期间、报告主体、报告对象、审计范围与覆盖单位数。
省级报告表达要点：突出围绕省委省政府中心工作；板块在法定框架下可包括财政管理审计、部门预算执行审计、重点专项审计（重大政策落实、重点民生资金、政府债务、政府投资项目等）、国有资产管理审计、审计建议；标注年度和审计范围。
问题条目统一按以下结构生成：**问题定性 → 事实描述 → 涉及主体 → 问题金额 → 定性依据 → 整改状态 → 审计处理意见**。问题定性必须使用报告原文表述，不自行改写或归并。对“审计期间已整改”的问题，表述为“审计指出该问题后，……已完成整改”。
区分四类内容，不得混编：**总体评价、审计发现、审计建议、整改情况**。审计建议应关联其针对的问题类型；整改情况应包含已整改金额、完善制度数、追责问责人数等数据。
同一问题类型在不同年度、不同省份报告中的表述差异应保留原文，并标注“连续反映”“首次反映”“整改后未再出现”等状态。

## 四、非报告类页面表达重点
除报告页外，实体页与概念页按以下结构组织，保持 [[链接]] 互引，金额与口径保留原文：
- **机构组织页**：机构全称与简称 → 行政层级与隶属关系 → 与审计的关联（审计主体/被审计对象/整改责任方）→ 关联报告与人物；
- **人物页**：身份与职务 → 在报告中的角色（报告人、被追责人等）→ 关联报告与机构；
- **地点页**：行政层级与归属 → 涉及的审计事项；
- **资金资产页**：定义与口径 → 涉及的审计发现（附金额与年度）→ 相关建议与整改；
- **项目工程页**：项目名称与地点 → 建设内容与资金 → 涉及的审计问题；
- **会议事件页**：届次与时间 → 审议事项 → 关联报告；
- **概念页**：定义（以报告原文为准）→ 关联板块与问题类型 → 典型审计发现与建议引用。

## 五、首页表达重点
首页用于导航和概览，不写长正文。按库内实际容量组织入口：
- **按省份**：已入库的省级行政区（30 个）；
- **按年度**：2024、2025，支持跨年度比对；
- **按报告类型**：审计工作报告、整改报告、文字解读、图解；
- **按审计板块**：财政管理审计、部门预算执行审计、重点专项审计、国有资产审计、审计建议、整改情况；
- **按问题类型**：预算编制、预算执行、资金绩效、债务管理、政策落实、资产管理、财经纪律；
- **按整改状态**：已整改、正在整改、尚未整改、移送线索。
设置专项入口：**审计工作报告结构模板**、**问题表述用语对照**、**跨年度问题比对**、**整改追踪**。每个入口用一句话说明用途。展示高频检索条目和近期已入库报告，避免堆砌具体问题细节。

## 六、语气、术语与格式
正式、严谨、客观、规范。使用审计工作报告法定术语：审计工作报告、财政管理审计、部门预算执行审计、重点专项审计、国有资产审计、审计建议、整改情况、移送违纪违法问题线索等。使用“揭示”“查处”“移送”等审计监督专属动词。
问题定性使用报告原文，不自行归一。金额统一单位并注明口径，区分预算数、决算数、执行数。区分报告原文、报告解读、媒体解读。多用小标题、列表、表格组织内容。

## 七、边界
本要求只控制摘要、页面和首页的表达重点；引用、合并与防幻觉规则由系统固定维护。中央本级与市级报告入库后，按第三节补充相应组织要点，市级报告侧重本级预算管理和部门执行的操作性层面问题，保留“市级特有板块”标签。政策原文、报告解读、媒体解读应分开标注。修改后需重新解析，才会影响已有内容。
