## 刷新方法

部署目录：`/mnt/data/weknora`（compose 工作目录）。刷新时核对：

1. `docker ps` 中 WeKnora-* 容器组状态与端口
2. `cd /mnt/data/weknora && git log -1`（部署源码版本）
3. `docker inspect WeKnora-app --format "{{json .Mounts}}"`（挂载是否为新 —— **判据**，见下"挂载外置"）
4. `docker images --digests | grep weknora`（镜像构建时间）

## 三、挂载外置（四层）——判部署是否生效的依据

| 宿主机（/mnt/data/weknora 或 docker volumes） | 容器内 |
|---|---|
| `.build/WeKnora`（编译产物二进制） | `/app/WeKnora`（app） |
| `migrations/` | `/app/migrations` |
| `config/config.yaml` | `/app/config/config.yaml` |
| `docreader/` | `/app/docreader` |
| `my-frontend/dist` | `/usr/share/nginx/html`（frontend-wkj，**非只读**） |
| named volume `weknora_data-files` | `/data/files`（对象存储，STORAGE_TYPE=local） |
| named volume `weknora_docreader-tmp` | `/tmp/docreader` |

**判据**：提交 → 推送 → 部署后，用 `docker inspect` 挂载列表确认新代码已挂入；输出全绿 ≠ 挂载更新。

## 四、关键运行参数（app 启动日志实读）

- `AUTO_MIGRATE=true` ⇒ **每次 app 启动都会跑 pending 迁移**，动 app 前先备份（正式数据）。
- `RETRIEVE_DRIVER=postgres`、`STORAGE_TYPE=local`（MinIO/TOS 未启用）。
- Ollama：`host.docker.internal:11434`（**111 本机**，embedding 指向此，不指向 110）。
- Langfuse 观测已启用（OTLP，sample_rate=1.00）。
- 租户 RBAC：`enable_rbac=true`、`cross_tenant_access=false`。
- 模型并发：按模型治理，limit=32（redis 分布式）。
- 审计日志保留 90 天；SSRF 白名单 8 条主条目。
- 编排：官方 `docker-compose.yml` + `my-docker/docker-compose.overlay.yml`（叠加层，唯一需改的编排文件）。
