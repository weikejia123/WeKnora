## 记录规约

1. **沉淀优先记知识，少记易变信息**：机制/因果/判据/代码出处优先；临时路径、当日端口、
   一次性测试数据要么不记、要么注明"截至日期+当日实测"。
2. **引用用符号引用**（如 `internal/handler/knowledge.go` 的路由注册处），
   不写 `文件:行号`——`my-docs/` 已有约 90 处行号引用失真的教训。
3. **操作日志只追加不回改**：回答被推翻时在原条目加「⚠️ 后记」，不删原文。
4. **安全红线**：111 的数据层（PG / Neo4j / 对象存储 / `.env`）是正式数据；
   使用过程中的任何写操作（建库、导入、迁移）前后留痕；动 `app` 前先备份（`AUTO_MIGRATE` 机制）。
