# Wiki 提取重点

本设置仅说明在“预算执行和其他财政收支的审计工作报告”知识管理场景下，应重点识别的领域实体、概念与关系线索；不定义、不替换系统的 JSON 结构、字段名、引用协议，不改变合并与防幻觉规则。当前主要覆盖中央和省级报告，后续支持扩展至市级。

## 一、提取目标

从中央、省级（后续含市级）预算执行和其他财政收支的审计工作报告中，识别可独立成条、可链接、可追溯、可跨年度比对的实体和概念。核心提取原则：**以“报告层级 × 审计板块 × 问题类型 × 整改状态”为四维框架，优先提取有明确审计定性、有法定报告依据、有整改追踪价值的内容。**

## 二、重点实体类型

### 1. 报告本体类实体

- 报告全称，如《国务院关于××年度中央预算执行和其他财政收支的审计工作报告》《××省人民政府关于××年度省级预算执行和其他财政收支的审计工作报告》；
- 报告层级：中央 / 省级 / 市级；
- 报告年度、审计期间、报告主体（审计署 / 省审计厅 / 市审计局）、报告对象（全国人大常委会 / 省人大常委会 / 市人大常委会）；
- 报告结构板块：财政管理审计、部门预算执行审计、重点专项审计、国有资产审计、审计建议、整改情况、移送违纪违法问题线索等。

### 2. 审计板块类实体

- 中央财政管理审计、省级财政管理审计、市级财政管理审计；
- 中央部门预算执行审计、省级部门预算执行审计、市级部门预算执行审计；
- 重点专项审计：重大政策落实、重点民生资金、政府投资项目、地方政府债务、国有资产管理等；
- 国有资产审计：行政事业性国有资产、企业国有资产、国有自然资源资产；
- 审计建议、整改情况、移送线索。

### 3. 财政与专项审计实体（按板块归组）
- 财政管理：四本预算、零基预算、转移支付、专项债券、超长期特别国债、国库集中支付、决算草案；
- 部门预算执行：部门与所属单位、无预算/超预算支出、预算调剂、以新还旧、绩效管理、资产闲置与处置；
- 重点专项：重大政策落实、重点民生资金（医保、教育、养老、高标准农田等）、政府投资项目（招投标、竣工决算）、国有资产。

### 6. 问题定性实体

必须保留报告原文表述，不自行改写或归并。常见类型包括：

- 预算管理类：“预算编制不完整”“预算调整不合规”“支出固化”“零基预算改革推进不到位”；
- 执行合规类：“无预算支出”“超预算支出”“违规批复预算”“预算调剂不规范”“以新还旧”；
- 资金绩效类：“资金使用效益不高”“专项资金拨付滞后”“存量资金未有效盘活”“资金闲置”；
- 债务管理类：“专项债券监管不严”“项目申报审核不严”“资金拨付不及时”“项目收益未达预期”；
- 政策落实类：“政策执行有偏差”“减税降费政策未全面落实”“征收过头税费”；
- 资产管理类：“资产底数不清”“资产闲置或低效使用”“资产处置不规范”；
- 财经纪律类：“违反中央八项规定精神”“落实过紧日子要求不到位”“财经纪律执行不够严格”。

### 7. 整改与追责实体

- 整改状态：立行立改、分阶段整改、持续整改、已完成整改、正在整改、尚未整改；
- 整改成效数据：已整改问题金额、制定完善制度数、追责问责人数、处理处分人数；
- 整改类型标签：全面整改、专项整改、重点督办；
- 移送线索：移送纪检监察机关问题线索数、移送主管部门问题线索数。

### 8. 审计建议实体

- 建议方向：强化财政资源资产统筹、深化预算管理体制改革、化解重点领域风险、加强财政资金绩效管理、严守财经纪律；
- 建议与问题的对应关系：每条建议应关联其针对的问题类型。

### 9. 金额、比例与指标实体

- 预算执行数据：一般公共预算收入总量/支出总量、赤字规模、政府性基金预算收支、国有资本经营预算收支、社会保险基金预算收支；
- 问题金额：审计发现主要问题金额、已整改问题金额；
- 审减率、整改率、覆盖率等指标；
- 必须标注口径（预算数/决算数/执行数）、单位（万元/亿元）、年度、报告层级。

## 三、重点概念类型

- 审计工作报告的法定报告框架与内容要求；
- 预算执行审计与其他财政收支审计的关系；
- 财政管理审计与部门预算执行审计的分工；
- 审计整改“下半篇文章”与整改总体格局；
- 研究型审计与“经济体检”定位；
- 揭示问题与促进治理相结合的报告逻辑；
- 总体评价与具体问题的区分表述；
- 跨年度问题比对与“连续反映”“首次反映”“整改后未再出现”等状态标记；
- 中央、省、市三级报告在板块设置、问题侧重、表述风格上的差异。

## 四、别名与消歧

1. 识别全称、简称与报告内简称。例：《国务院关于××年度中央预算执行和其他财政收支的审计工作报告》= 中央审计工作报告；省级报告 = “关于××年度省级预算执行和其他财政收支的审计工作报告”。

2. 同名不同义需按层级和语境区分：
   - “财政管理审计”在中央报告指中央财政管理审计，在省级报告指省级财政管理审计，板块名称相同但审计对象不同；
   - “部门预算执行审计”在中央报告指中央部门，在省级报告指省级部门；
   - “重点专项审计”各年度、各层级涵盖领域不同，必须标注年度和层级。

3. 问题表述的年度差异需保留：同一类问题在不同年度报告中可能用不同措辞，应保留原文表述并建立关联关系，不强行统一。

4. “审计建议”与“整改要求”是不同概念：审计建议是报告结尾对宏观管理提出的方向性意见，整改要求是对具体问题提出的处置要求，不得混用。

## 五、关系线索

优先识别以下关系：

- **层级关系**：中央报告 → 省级报告 → 市级报告，同一审计板块在不同层级的审计对象和侧重点差异；
- **板块关系**：财政管理审计 ↔ 部门预算执行审计 ↔ 重点专项审计 ↔ 国有资产审计，各板块之间的逻辑关系和覆盖范围；
- **问题—建议关系**：具体问题 → 对应的审计建议方向；
- **问题—整改关系**：审计发现的问题 → 整改状态 → 整改措施 → 追责问责情况；
- **年度比对关系**：同一问题类型在不同年度报告中的“首次反映/连续反映/整改后未再出现”；
- **主体关联**：财政部门 ↔ 预算单位 ↔ 项目主管部门 ↔ 地方政府，同一问题涉及的多方主体。

## 六、文件夹归位规则

以下规则基于库内已有页面的实测梳理，约束页面归入的文件夹与 page_type 判定。

**类型根（实体页专用，一页只进一个）**：
- 报告文件/：审计工作报告、整改报告、解读文章、规划与实施方案；
- 机构组织/：审计机关、财政与行业主管部门、人大常委会、纪委监委、人民政府、供销合作社等所有组织，不按主题分散、不按审计与非审计分设；
- 人物/：具名自然人；
- 地点/：省、市、县、区域、功能区、枢纽；
- 资金资产/：制度性资金品种（基本养老保险基金、住宅专项维修资金等）与国有资产类别；
- 项目工程/：具体建设项目、工程、信息系统平台（高速公路建设项目、公务用车管理平台等）；
- 会议事件/：人代会及人大常委会会议，以及运动会等一次性重大活动。

**概念根（concept 页专用）**：审计概念/（板块、问题定性、整改状态）、财政概念/（预算、债务、转移支付、过紧日子要求）、民生政策概念/（民生领域与政策理念）。

**判定准则**：
1. 类型轴优先于主题轴：凡可指认的具体对象一律进对应类型根，禁止按主题放入"社会民生""政治政策"等主题文件夹；概念根根下不得直挂实体页；
2. 概念根下只放 concept 页，不与实体混放；
3. concept/entity 判定：可数、有专名、可独立指认为 entity；抽象、可复用、描述一类事物为 concept。边界："XX基金/资金"指品种本身→资金资产/（entity），指其监管活动→concept；资产"类别"→entity，资产管理"活动/要求"→concept；"第X届人大常委会第X次会议"是事件不是组织→会议事件/；规划、试点与实施方案是文件→报告文件/，不是概念。

**建链要求**：报告页↔机构页↔人物页↔概念页保持互链；同一实体的全称、简称链接到同一页面。

## 七、提取优先级
高：报告名称/层级/年度/期间/主体、各板块问题条目及定性、涉及主体与金额、整改状态与成效数据（已整改金额、制度完善数、追责人数）。中：总体评价表述、审计范围与覆盖单位数、移送线索、跨年度比对结果。低：背景形势性表述、宣传性总结、无审计含义的程序性内容。谨慎提取：未注明出处的地方做法、预测评价性表述、仅见于解读未经正文确认的内容。

## 八、报告层级扩展机制
市级报告入库时：识别"复用板块"与"市级特有板块"（如乡镇预算执行审计、殡葬领域专项调查）；提取市级特有问题类型（如"以新还旧"、项目执行率远低于时序进度）；建立与省级同类问题的"上下级共性/市级特有"关联；市级总体评价与建议更贴近操作层面，分开提取。

## 九、边界

本设置只说明提取重点，不定义 JSON 字段，不改变引用协议，不替代系统合并与防幻觉规则。报告层级清单保持开放，支持后续扩展。问题定性表述以报告原文为准，不自行归一或改写。政策原文、报告解读、媒体解读应分开标注。修改后需重新解析，才会影响已有内容。
